Shortcut keys for copy and paste
Action	Linux Terminal / AWS SSH	Windows Terminal / WSL
Copy	Ctrl + Shift + C	Ctrl + Shift + C or Ctrl + C
Paste	Ctrl + Shift + V	Ctrl + Shift + V or Ctrl + V
Stop a running command	Ctrl + C	Ctrl + C
Clear terminal screen	Ctrl + L	Ctrl + L

Shift + Insert is a keyboard shortcut used to paste copied text into a terminal. It is an alternative to Ctrl + Shift + V in many Linux terminals.
